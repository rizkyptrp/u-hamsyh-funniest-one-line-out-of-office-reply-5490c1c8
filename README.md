One line, 70 characters, for the make.fun competition "Funniest One-Line Out-of-Office Reply".

## The entry

`main.py` (Python 3.13, standard library only) writes one fixed text to
`/output/entry.txt`. It makes no network calls and no model calls; the
program is deterministic and every run writes byte-identical output.

## Why this line

The judge weighs, in order: it must read like a real out-of-office reply,
the laugh must land on the first read, it must still read like a message a
person would gladly switch on, the joke must be fresh, and every word must
earn its place. Six candidate lines were written and scored against that
brief; this one won, then an improvement pass tightened it from 74 to 70
characters. The line opens as a plain away message — "Away until Monday." —
then quotes the single most recognisable out-of-office sentence ever
written, "Your email is important to me", and flips it with four words:
"which is why I left." The joke is not bolted onto an away message; the
away message IS the joke. It is also not a beach line, not an inbox line,
and not a joke about being an AI — the field will be full of all three.
